# packs are listed by what type they are (journal, scene, actor, etc.)
# packs with * are OBSERVABLE by players
# folders are marked with /name
# custom pack names can be set with : "label" (i.e. items: "Actions" would become an item pack named Verndhelt Actions)
# final pack names use the full folder path + label (or type if label doesn't exist) so i.e. Covalon Basics Journals or Covalon Mentors (except expeditions which only use expedition location name).
# if label matches the last folder it was in, it is not repeated (so it becomes Covalon Mentors instead of Covalon Mentors Mentors).

# available pack types:
# actors, items, scenes, journals, macros, rolltables, playlists, adventures
